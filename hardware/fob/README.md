# Fob board

The trigger fob's PCB, generated by code from the circuit outward. The pipeline is adapted from
tinycrypt's `hardware/key-board` (circuit as Python, EasyEDA footprints via easyeda2kicad,
Freerouting, KiCad DRC, then JLCPCB fab files). The design is in
[`docs/superpowers/specs/2026-11-05-iphone-remote-fob-design.md`](../../docs/superpowers/specs/2026-11-05-iphone-remote-fob-design.md).

**Stage:** circuit done (IREM-3). Placement, routing and gerbers come with the layout (IREM-4).

## Build

```bash
ASDF_PYTHON_VERSION=3.11.15 python -m venv .venv
.venv/bin/pip install -r requirements.txt
./fetch_parts.sh             # only if footprints/ is missing or a part is added (resumable)
.venv/bin/python build.py    # out/fob/: bom.csv, netlist.txt, pins.h
.venv/bin/python -m pytest
```

There's no drawn schematic: `board/fob_board.py` *is* the schematic, and `out/fob/netlist.txt`
lists every net. Comments in it carry Nordic's reference designators (C1 to C10, L1 to L3, X1)
so it can be checked line by line against Nordic's "QCAA QFN32 with DC/DC regulator setup".

"Economic and Standard" on its JLC page on 5 Nov 2026.

## Layout rules carried into IREM-4

- **Antenna** (Johanson datasheet, evaluation-board layout): edge-mounted, on the board edge,
  with **no copper on any layer** in a 4.0 × 6.0 mm area around it (pads plus 4.1 mm into the
  board). No battery or metal under it. Grounded-coplanar 50 Ω feed through the R3/CA1/CA2 π.
- Put the antenna at the end away from the button and the CR2032 holder.
- Everything on the top side (JLC Economic). The bottom is ground pour.

## Footprint notes

- `fetch_parts.sh` hit EasyEDA's rate limit for four basic two-pin passives (C1035, C27143,
  C25117, C26083). They use already-fetched footprints of the same package (C0603, L0402,
  R0402), with pin name = pad number, which is all a two-pin part needs.
- The EasyEDA symbols type every pin "unspecified", so `check()` can't catch an unconnected
  power pin; `tests/test_fob_board.py` checks every nRF52810 pad explicitly.
- `footprints/local.pretty` holds KiCad 10 stock footprints: the TC2030 legged footprint, the
  solder jumper and the 2×6 1.27 mm header.
